# Lista de Tarefas

Aplicação web para gerenciamento e listagem de tarefas desenvolvida com HTML, Tailwind CSS e JavaScript.

## Funcionalidades

- **Autenticação**: Interface para tela de login e navegação para cadastro.
- **Painel de Tarefas**: Visualização e organização das tarefas em cards interativos.
- **Design Moderno**: Estilizado com Tailwind CSS, proporcionando interface limpa e responsiva.

##  Estrutura de Arquivos

```
lista-tarefa/
├── index.html          # Página de Login
├── tarefas.html        # Página principal de gerenciamento de tarefas
├── index.js            # Lógica e manipulação do DOM
├── tailwind.config.js  # Configurações do Tailwind CSS
└── README.md           # Documentação do projeto
```

##  Tecnologias Utilizadas

- [HTML5](https://developer.mozilla.org/pt-BR/docs/Web/HTML)
- [Tailwind CSS](https://tailwindcss.com/)
- [JavaScript](https://developer.mozilla.org/pt-BR/docs/Web/JavaScript)

##  Como executar o projeto

1. Clone o repositório:
   ```bash
   git clone https://github.com/luan-Silva-Dev-0fc/lista-tarefa.git
   ```
2. Abra a pasta do projeto:
   ```bash
   cd lista-tarefa
   ```
3. Abra o arquivo `index.html` ou `tarefas.html` no seu navegador (ou utilize a extensão Live Server no VS Code / editor de sua preferência).
